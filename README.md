🎯 Descrição

Na aula de hoje desenvolvi um formulário em PHP com o tema Pokémon.
O projeto simula uma Pokédex interativa, onde é possível cadastrar, editar e liberar (excluir) Pokémons diretamente de um banco de dados MySQL.

🕹️ Funcionalidades

📝 Cadastro de Pokémon
O usuário insere o Nome e o Tipo do Pokémon em um formulário.
📋 Exibição na Pokédex
Após o cadastro, o Pokémon aparece em uma tabela com as seguintes informações:
🆔 ID automático
🔤 Nome
🔥 Tipo

⚙️ Botões de Editar e Excluir

✏️ Edição de Pokémon
Ao clicar em Editar, o usuário é redirecionado para uma nova tela onde pode alterar o nome e o tipo do Pokémon.
🗑️ Liberação (Exclusão)
Ao clicar na pokébola, o Pokémon é “liberado” — ou seja, excluído da Pokédex.

💻 Tecnologias Utilizadas

🐘 PHP (para o backend e interação com o banco de dados)
🗄️ MySQL (armazenamento dos Pokémons)
🎨 HTML + CSS (estrutura e estilo da página)
